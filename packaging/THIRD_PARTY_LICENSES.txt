ChessTrainer - third-party components in this build
====================================================

Stockfish (engine/stockfish/)
  GNU General Public License v3. The full licence (Copying.txt), authors and the complete
  source code are included in engine/stockfish/. https://stockfishchess.org

Lichess chess-openings dataset (chesstrainer/openings/data/)
  CC0 1.0 (public domain dedication). https://github.com/lichess-org/chess-openings

Piece classifier (models/square_classifier_free.onnx)
  Trained only on synthetic boards drawn with these free-licensed Lichess piece sets:
  cburnett (GPLv2+), chessnut (Apache-2.0), pirouetti (AGPLv3+), pixel (AGPLv3+),
  rhosgfx (CC0-1.0), spatial (MIT), celtic (MIT), mpchess (GPLv3+), totoy (CC BY 4.0),
  papercut (CC BY 4.0), and Lichess board textures (AGPLv3+).
  The CC BY-NC-SA piece sets used for the development model are NOT used for this model, and no
  piece or board images are included in this build.
  Piece set sources and licences: https://github.com/lichess-org/lila (COPYING.md).

Python libraries bundled by PyInstaller
  PyQt6 / Qt 6 (GPLv3 / LGPLv3), OpenCV (Apache-2.0), NumPy (BSD), python-chess (GPLv3),
  mss (MIT), Pillow (MIT-CMU), PyYAML (MIT), python-dotenv (BSD), anthropic SDK (MIT) and
  their dependencies (httpx, pydantic, ...), each under its own licence.

Because PyQt6, python-chess and Stockfish are GPLv3, redistributed builds must be
GPLv3-compatible.
